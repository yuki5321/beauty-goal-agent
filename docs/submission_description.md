## 2. プロジェクトの説明（提出フォーム用テキスト）

### 【対象とするユーザー像と課題】
- **対象ユーザー**: 自分に似合うメイクが分からずSNSのテクニック（中顔面短縮、小顔メイク等）を真似して失敗を繰り返している方、およびAIの容姿採点に傷ついた経験のあるすべての方。
- **課題① 美容における試行錯誤の莫大なコスト**: 骨格やパーツ比率は個人ごとに異なり、SNS動画を真似しても「チークの位置が合わない」「眉を下げすぎて不自然」などの失敗が多発。コスメの買い直しや毎日の手探りメイクに多大な時間と費用を浪費しています。
- **課題② 既存美容AIのルッキズムとコンプレックス助長**: 多くの美容AIは「黄金比診断」や「美人度スコア（例: 62点）」を提示します。これは他者基準の美の押し付けであり、身体違和症（ディスモルフィア）を助長する倫理的リスクを孕んでいます。

### 【課題へのソリューションと特徴】
AIはユーザーの顔を審判・採点しません。主権は常にユーザーにあり、ユーザーが設定した「Goal（中顔面を短く見せたい等）」に向けて、エージェントが自律的に試行錯誤して最適なレシピを導出します。

1. **自律試行錯誤 OODA ループ（Replan Engine）**:
   - **Observe**: YouCam MCPで顔の三分割比率を客観測定。
   - **Orient & Decide**: Geminiが錯視パラメータ（Plan A）を初期策定。
   - **Act**: チーク・リップ・下瞼・前髪のバーチャル試着を適用。
   - **Evaluate (Critic)**: Gemini 2.0 Flash のマルチモーダル推論で目標達成率（72%未達）と課題を自己批評。
   - **Replan**: 反省点を取り入れ、チーク重心低下＋涙袋追加の Plan B を再試行し、目標基準（88%）へ自律収束。
2. **錯視サイエンス解析オーバーレイ（Visual Explainability）**:
   - AIが施したスタイリングが「なぜその目標を達成できているのか」を、幾何学ネオンガイド（人中短縮 -3.2mm、視覚重心 ↓12px、余白カット -21%、中顔面比 0.355→0.312）としてビジュアル可視化。ブラックボックスな画像処理を排し、錯視物理学に基づく確固たる根拠を直感的に証明。
3. **現場感あふれるスマートミラー（Webカメラ即時自撮りモード）**:
   - メイク時は手が塞がっている現場のリアルを踏まえ、ブラウザインカメラから枠線ガイドに合わせてワンクリックで撮影・即推論開始。「日常で本当に使えるエージェント」を実現。
4. **環境光シミュレータ（自然光 / オフィス蛍光灯 / カフェ暖色光 / ナイト）**:
   - 日常生活の様々な照明シーン（5500K自然光、4000Kオフィス蛍光灯、2700Kカフェ暖色光、2200Kナイトバー）での錯視効果を瞬時に切り替え検証。光環境が変わっても錯視バランス（人中短縮・余白カット）が破綻しないことを実証。
5. **Gemini Google Search Grounding による実在コスメ処方箋（ハルシネーション抑止）**:
   - キャンメイク、KATE、セザンヌなど実在の市販コスメを提案する際、Gemini 2.0 Flash の **Google Search Grounding（Web検索グラウンディング）** を実行。架空の品番を完全抑止し、実勢価格・公式リンク付きで処方箋カード（高精細PNG）として保存可能。
6. **協調型微調整（Human-in-the-Loop Replan）**:
   - 収束後、「リップをもう少しナチュラルに」「前髪なしも試したい」と対話するだけで、エージェントが錯視効果を保ちながらユーザーの好みに合わせて柔軟に再調整。
7. **第5回審査基準に完全適合した厳格なガバナンス（Responsible AI）**:
   - **N-G01 反ルッキズム**: 容姿批判語句や点数化表現を物理的に遮断。
   - **N-G02 ディスモルフィア抑止**: 骨格歪曲率 0.00%（物理的骨格変形ツールの使用を禁止し、現実のメイク錯視に限定）。
   - **N-G03 生体データ保護**: Cloud Run の RAM（揮発メモリ）上のみで処理し、ディスク/DB永続化を禁止。セッション終了時/300秒TTLでゼロトレース消去。
   - **N-G04 サーキットブレーカー**: 最大3反復制限による無限ループ・コスト浪費の防止。

## 3. 利用した技術スタック（Google Cloud & スポンサー）

### （必須）Google Cloud アプリケーション実行プロダクト
- **Google Cloud Run**:
  - フロントエンド（React 19 / Vite）とバックエンド（FastAPI）を統合した単一コンテナでデプロイ。待機時インスタンス0件（コスト0円）による極めて高い費用対効果とスケーラビリティを実現。

### （必須）Google Cloud AI 技術
- **Google Gemini API（Gemini 2.0 Flash）**:
  - スタイリング仮説策定（Planning）および、生成画像のマルチモーダル自己評価（Critic Agent）。
- **Gemini Google Search Grounding（Grounding with Google Search）**:
  - Gemini 2.0 の Google 検索ツール連携により、市販コスメの最新品番・カラー・実勢価格・公式URLをリアルタイムグラウンディングし、AIハルシネーションを完全排除。

### （任意）Google Cloud その他のサービス
- **Google Cloud Logging**:
  - エージェントの Thought / Action / Observation / Score / ガバナンス検査ステータスを完全構造化 JSON ログとしてリアルタイム集約。
- **Google Cloud Trace**:
  - SSEストリーミングにおける各OODAステップのEnd-to-Endレイテンシ追跡。

### （任意）Support スポンサー技術
- **YouCam API / YouCam MCP Server（パーフェクト株式会社）**:
  - 顔のパーツ間比率・ランドマーク抽出、チーク・リップ・アイメイク・前髪のバーチャル試着シミュレーション。
