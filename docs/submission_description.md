## 2. プロジェクトの説明（提出フォーム用テキスト）

### 【対象とするユーザー像と課題】
- **対象ユーザー**: 「中顔面短縮」「小顔」などのメイクをSNSで見て試したものの、自分の顔立ちに合わせ方が分からない人。そして、AIに顔を採点されることに抵抗がある人。
- **課題① 試行錯誤のコスト**: 顔のパーツの比率は人それぞれで、動画の通りにしても同じ効果が出るとは限りません。チークの位置やリップの描き方を探るために、コスメの買い直しや毎朝の手探りが続きます。
- **課題② 美容AIのルッキズム**: 多くの美容AIは「黄金比との差」や「美人度○点」のように顔そのものを採点します。他人の基準を押し付け、コンプレックスを強めるおそれがあります。

### 【ソリューション】
AIは顔を採点しません。ユーザーが選んだ Goal（例: 中顔面を短く見せたい）に向けて、エージェントが「メイクと前髪でどこまで印象を動かせたか」だけを評価し、試着 → 評価 → 再計画を自律的に繰り返して、明日から再現できるレシピを導きます。

### 【エージェントの動き（OODA ループ）】
1. **OBSERVE**: YouCam API の顔分析（`horizontalThird`）で、顔の三分割比率（上・中・下）を計測します。
2. **ORIENT**: 計測した中顔面比率と目標比率の差を確認します。錯視アナリスト・スタイリスト・ガバナンス担当の3つの観点から方針を検討し、ガバナンス担当が安全上限をチェックします。
3. **DECIDE**: Gemini が、控えめな強さから始める Plan A を JSON で立案します。調整する項目は7つです（チークの配置・色・濃さ、オーバーリップ倍率、リップの濃さ、涙袋の強調、前髪スタイル）。出力は、許可された値と安全上限に必ず補正します。
4. **ACT**: YouCam API で前髪（Hair Bang）を試着し、その結果画像にメイク（チーク・リップライナー・リップ・涙袋）を重ねて試着します。
5. **EVALUATE**: Gemini が元画像と試着画像を見比べ、「元画像からの印象のシフト」をチーク・リップ・涙袋・前髪の要素別に 0〜100 で採点します。総合点はコードで重み付き平均します（チーク0.3・リップ0.25・涙袋0.25・前髪0.2。前髪が画像に反映されなかった場合は除外）。
6. **REPLAN**: 目標（85%）に届かなければ、エージェントが自ら仮説を棄却します。評価役の指摘をもとに Gemini が次の Plan を立て、前回と同じ案しか出なければ評価役の調整案を使います。最大3回で終了し、届かなかった場合は最も良かった案を採用します。

**実行例（実写真・YouCam API・Gemini 使用）**: 中顔面比率 0.350（目標 0.310）→ Plan A 84%（チーク82 / リップ84 / 涙袋80 / 前髪92）→ Plan B（チークの濃さ 45→50、オーバーリップ ×1.08→×1.12、涙袋 45→55%）で 86% に達し、収束しました。

### 【主な機能】
- **Before / After スライダーと解析パネル**: 要素別の評価と、使ったパラメータ（チークの配置・濃さ、オーバーリップ、リップの濃さ、涙袋、前髪）を表示します。比率モデルによる中顔面比率の推定値は、参考値として分けて表示します。
- **前髪の系統選択**: レディース / メンズの前髪テンプレートは、利用者が画面で選びます。写真から性別を推定することはしません。
- **対話による微調整（Human-in-the-Loop）**: 「リップをもう少しナチュラルに」「前髪なしも試したい」などの要望を Gemini が解釈してパラメータを更新し、もう一度試着します。要望の文章はデータとして扱い、その中に書かれた指示には従いません。
- **実在コスメの確認（Google Search Grounding）**: レシピで提案する市販コスメを、Gemini の Google 検索ツールで確認します。検索結果で確認できた商品にだけ「検索確認済」を表示します。
- **処方箋シートの保存**: レシピと商品を PNG 画像として保存できます。
- **カメラ撮影と環境光の切り替え**: インカメラでその場で撮影できます。仕上がりは、自然光・オフィス・カフェ・夜の照明で見比べられます。
- **フォールバック**: Gemini のキーがない場合はルールベースの計画と比率モデルで評価し、YouCam API が失敗した場合は内蔵シミュレータで試着画像を作ります。デモが止まらないようにするためです。

### 【Responsible AI とガバナンス】
- **N-G01 反ルッキズム**: 容姿を貶める言葉や採点表現を入力・出力の両方で遮断します。評価は顔立ちではなく「メイクによる印象のシフト」だけです。
- **N-G02 骨格変形なし**: 顔の形や唇の形を変える加工は使いません。パラメータはメイクで再現できる範囲に上限を設けています（オーバーリップは最大 ×1.3、濃さは最大 90）。
- **N-G03 生体データ最小化**: アプリ側では写真をメモリ上でのみ扱い、ディスクや DB に保存しません。セッション終了時、または 300 秒で破棄します。試着と顔分析のために写真を YouCam API（Perfect Corp）へ送信し、先方では最大24時間保持されることを、画面と監査証明書で明示しています。
- **N-G04 回数の上限**: ループは最大3回です。APIエラーの場合も安全に終了します。
- **監査証明書**: 実行ごとに、規程の適用状況・パラメータ・反復回数を JSON で表示します。

## 3. 利用した技術スタック

### Google Cloud アプリケーション実行プロダクト
- **Cloud Run**: React（Vite）のフロントエンドと FastAPI のバックエンドを1つのコンテナにまとめ、`gcloud run deploy --source .` でデプロイしています（asia-northeast1）。エージェントの思考過程は SSE でリアルタイムに配信します。

### Google Cloud AI 技術
- **Gemini API（`gemini-3.8-flash`、google-genai SDK）**:
  - スタイリング計画の立案と再計画（JSON 出力。値は安全上限に補正）
  - 試着画像のマルチモーダル評価（要素別スコア）
  - 対話での要望の解釈
  - Google Search Grounding による市販コスメの確認

### その他
- **Cloud Logging**: Thought / Action / Observation / スコア / ガバナンス検査の結果を、構造化 JSON ログとして標準出力に書き、Cloud Logging で確認できるようにしています。
- **YouCam API（Perfect Corp）**: 顔分析（`face-attr-analysis`）、前髪の試着（`hair-bang`）、メイクの試着（`makeup-vto`）。
