# Beauty Goal Agent 3分デモ動画 絵コンテ・ナレーション台本

> **第5回 Agentic AI Hackathon with Google Cloud 提出用**
> 想定尺: 2分50秒 〜 3分00秒
> テーマ: 顔を採点しない。なりたい印象に向けて、AIが試着と評価を自分で繰り返すメイク・前髪エージェント。

収録は Cloud Run 上のアプリ（YouCam API・Gemini 使用）で行う想定です。点数とパラメータは実際の実行例（中顔面比率 0.350 → Plan A 84% → Plan B 86%）を使っています。点数は実行ごとに変わるので、収録した回の値に合わせてナレーションを差し替えてください。

## 🎬 シーン別 絵コンテ & ナレーション

### シーン 1: 課題提起（0:00 〜 0:25）
- **画面**: タイトル「Beauty Goal Agent」→ 課題スライド（「顔を点数で評価するAI」「SNSメイクを真似しても合わない」）。実在アプリの画面は使わず、自作のイメージにします。
- **ナレーション**:
  > 「顔を点数で評価する美容AIは、他人の基準を押し付け、コンプレックスを強めてしまうことがあります。
  > 一方、SNSで流行る『中顔面短縮メイク』も、顔の比率は人それぞれで、真似しただけではうまくいきません。
  > Beauty Goal Agent は、顔を採点しません。あなたが選んだ『なりたい印象』に向けて、AIが試着と評価を繰り返し、再現できるレシピを見つけます。」

### シーン 2: Goal 設定と写真の扱い（0:25 〜 0:55）
- **画面**:
  - ブラウザで Cloud Run のアプリを開きます（アドレスバーの `…run.app` を映す）。
  - 写真を選択します（または「カメラで撮影」）。
  - 前髪の系統「メンズ / レディース」の切り替えを映します。
  - Goal「中顔面短縮」を選択します。
  - 写真欄の「YouCam API へ送信・先方で最大24時間保持」の表示を映します。
- **ナレーション**:
  > 「写真を選び、Goal に『中顔面短縮』を選びます。前髪の系統は自分で選びます。AIが写真から性別を推定することはありません。
  > 写真はアプリ側ではメモリ上だけで扱い、保存しません。試着のために YouCam API へ送られ、先方で最大24時間保持されることも画面に明示しています。」

### シーン 3: 自律ループの実演（0:55 〜 1:50）★最大の見せ場
- **画面**: 「エージェント最適化を開始」をクリックし、ターミナルのログを順に映します。
  - **OBSERVE**: YouCam の顔分析 → 三分割 29/35/36%、中顔面比率 0.350（目標 0.310）
  - **ORIENT**: 錯視アナリスト・スタイリスト・ガバナンスの3役が方針を確認
  - **DECIDE**: Gemini が Plan A を立案（チーク 小鼻下・横長（濃さ45）/ オーバーリップ ×1.08（濃さ45）/ 涙袋 45% / 前髪 シースルー）
  - **ACT**: YouCam で前髪 → メイクの順に試着
  - **EVALUATE**: 84%（チーク 82 / リップ 84 / 涙袋 80 / 前髪 92）→ 未達
  - **仮説棄却 & ピボット**: Plan B（チーク濃さ 45→50、オーバーリップ ×1.08→×1.12、リップ濃さ 45→48、涙袋 45→55%）
  - **再評価**: 86% → Goal 達成で収束
- **ナレーション**:
  > 「開始すると、エージェントがループを回し始めます。
  > まず YouCam API で顔の三分割比率を計測。中顔面は 0.350、目標は 0.310 です。
  > Gemini が控えめな Plan A を立て、YouCam で前髪とメイクを試着します。
  > Gemini が元の写真と見比べ、顔立ちではなく『メイクで印象がどれだけ動いたか』を、チーク・リップ・涙袋・前髪ごとに評価します。結果は84%、目標の85%に届きません。
  > するとエージェントは自分で仮説を棄却し、チークとリップの濃さ、オーバーリップ、涙袋を一段ずつ強めた Plan B へ切り替えます。
  > 再評価は86%。目標に届いたので、ここで収束しました。」

### シーン 4: Before/After と解析パネル、レシピ（1:50 〜 2:20）
- **画面**:
  - Before / After スライダーをゆっくり左右に動かします。
  - 「錯視サイエンス解析」をONにし、要素別評価と6タイル（チーク配置・チーク濃さ・オーバーリップ・リップ濃さ・涙袋強調・前髪）を映します。
  - 環境光を「オフィス」「カフェ」に切り替えます。
  - レシピカードと「検索確認済」バッジを映し、「処方箋シートを画像保存 (PNG)」をクリックします。
- **ナレーション**:
  > 「スライダーで比べると、骨格はそのままに、メイクと前髪だけで印象が変わっているのが分かります。
  > 解析パネルには、要素ごとの評価と、実際に使ったパラメータを表示します。比率の数字はメイク量からの推定値で、参考として分けて表示しています。
  > 照明を切り替えて見え方を確かめることもできます。
  > レシピの市販コスメは Gemini の Google 検索で確認し、確認できた商品に『検索確認済』を付けます。シートは画像で保存できます。」

### シーン 5: 対話で微調整（2:20 〜 2:40）
- **画面**: 「エージェントと対話して微調整する」で「リップをもう少しナチュラルに落ち着かせたい」を送信し、再計画と再試着の結果を映します。
- **ナレーション**:
  > 「『リップをもう少しナチュラルに』と伝えると、Gemini が要望を解釈してパラメータを更新し、もう一度試着します。好みに合わせて、何度でも調整できます。」

### シーン 6: ガバナンスとまとめ（2:40 〜 3:00）
- **画面**: 「監査証明書を確認」→ モーダル（N-G01〜N-G04）→ 構成図 `docs/architecture_diagram.png`。
- **ナレーション**:
  > 「容姿を採点しない、骨格を変えない、写真を保存しない、ループは最大3回。この4つの規程を、実行ごとに監査証明書で確認できます。
  > Cloud Run と Gemini、YouCam API で動く Beauty Goal Agent が、あなたのなりたい印象に伴走します。」

## 💡 収録のポイント
1. **事前に1回実行しておく**: YouCam の試着は1回の実行に数十秒かかります。本番の収録の前に、同じ写真で一度動かして所要時間を確認し、待ち時間は編集で短縮してください。
2. **写真**: 正面・顔全体・肩まで写った写真を使うと、前髪の試着まで反映されます。人物の写真は、本人の許可を得たもの、または生成画像を使ってください。
3. **アドレスバー**: `…run.app` が映るようにすると、Cloud Run で動いていることが伝わります。
4. **スライダー**: ゆっくり往復させると違いが伝わりやすくなります。
5. **音声**: BGM は小さめにして、ナレーションを優先してください。
