# Beauty Goal Agent（ビューティー・ゴール・エージェント）

> **「似合う」を押し付けない。ユーザーのなりたい顔へ、AIが試行錯誤で伴走する自律型メイク・スタイリング最適化エージェント**

---

## 🌟 プロジェクト概要

「中顔面短縮」「小顔」「求心・遠心補正」など、顔の錯視効果を狙ったメイク手法が注目されています。しかし、骨格やパーツ比率は個人ごとに異なり、SNSの動画を真似しても失敗が多発しています。
また、既存の多くの美容AIは「黄金比診断」や「美人度スコア（例: 60点）」といった他者基準の美を押し付け、ルッキズムやディスモルフィア（身体醜形懸念）を助長する倫理的リスクを孕んでいます。

**Beauty Goal Agent** は、AIがユーザーの顔を審判・採点しません。主権は常にユーザーにあり、ユーザーが設定した「Goal（中顔面短縮など）」に向けて、エージェントが **YouCam MCP**（バーチャル試着）と **Gemini**（マルチモーダル評価・批判）を駆使し、**OODAループ**によって自律的に試行錯誤（Replan）を繰り返して最適なメイク＆前髪レシピを導出します。

---

## 🛡️ Responsible AI & ガバナンス（審査重点項目）

- **N-G01: 反ルッキズム・非採点規程**:
  - プロンプトおよびUIにおいて「ブサイク」「改善」「劣っている」「点数」といった評価表現を物理的に禁止。「比率の視覚的調整」「印象のシフト」というニュートラルな表現に統制。
- **N-G02: ディスモルフィア抑止（骨格変形リミッター）**:
  - YouCamの骨格リシェイプ系ツール（`AI_Face_Reshape` 等）の使用を遮断。メイクや前髪による「現実的な錯視効果」の範囲内にパラメータをハードリミット。
- **N-G03: 生体顔写真のデータ最小化と即時破棄**:
  - アップロードされた画像はRAM（メモリ）上でのみ処理。ファイルシステムやDBへの永続保存を禁止し、セッション完了時に即時消去。
- **N-G04: サーキットブレーカー**:
  - 試行錯誤ループの上限を最大3回に厳格制限。APIエラーや未収束時はその時点の最高スコアで安全終了。
- **5.1: Cloud Logging互換の完全構造化ログ**:
  - Thought、Action、Observation、Evaluation Score、ガバナンス検査ステータスをJSON構造化ログとして標準出力。

## 🚀 クイックスタートガイド

### 1. 環境設定

`backend/.env.example` を `backend/.env` にコピーし、APIキーを設定します。

```bash
# backend/.env
GEMINI_API_KEY=your_gemini_api_key_here
YOUCAM_API_KEY=your_youcam_api_key_here
USE_MOCK_YOUCAM=false   # APIキー未設定時またはオフライン時は true でシミュレータが動作
```

※APIキーをお持ちでない場合やテスト時は、自動的に高品位な内蔵シミュレータ（PIL画像合成エンジン）が動作するため、キー設定前でも全機能が動作確認可能です。

### 2. バックエンドの起動

```powershell
cd backend
.\.venv\Scripts\Activate.ps1
$env:PYTHONPATH="."
python run.py
```
- APIサーバー: `http://127.0.0.1:8000`
- ヘルスチェック: `http://127.0.0.1:8000/api/health`

### 3. フロントエンドの起動

別ターミナルで実行:
```powershell
cd frontend
npm run dev
```
- Web UI: `http://localhost:5173`

## 🎬 3分デモの動かし方（審査員への見せ方）

1. ブラウザで `http://localhost:5173` を開きます。
2. **Goal選択**: 「中顔面短縮（代表ユースケース）」を選択します。
3. **写真入力**: 「デモ用サンプル写真を読み込む」をクリック（または手元の自撮り写真をアップロード）。
4. **エージェント最適化を開始**:
   - **Step 1 OBSERVE**: YouCam APIが顔の三分割比率（中顔面比率 0.355）を客観抽出。
   - **Step 2 ORIENT**: 目標比率0.31とのギャップを特定。
   - **Loop #1**: Plan A（72%）→ Gemini Visual Criticが「チークの重心が高く頬の縦余白が残っている。下瞼に涙袋メイクが欠落」と自己批評。
   - **Step 6 REPLAN**: 反省点を反映し、チークを下げて涙袋シャドウを追加した Plan B へ自動更新。
   - **Loop #2**: Plan B（88%）→ 目標基準（85%）をクリアし推論ループが収束！
5. **Before / After 比較スライダー**:
   - 中央のスライダーを左右にドラッグして、骨格を変えず錯視だけで中顔面が短縮した変化を体感。
6. **再現メイクレシピ**:
   - 明日の朝自分で実践できるチーク・リップ・涙袋・前髪の解説レシピを確認・コピー。
